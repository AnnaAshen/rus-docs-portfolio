# **Описание конечной точки API: Регистрация пользователя**

`POST /api/v1/users/register`

Создаёт новую учётную запись пользователя.

## **Формат данных**

Тело запроса и описанные ниже тела ответов передаются в формате JSON.

Заголовок запроса:

```http
Content-Type: application/json
```

Заголовок ответа:

```http
Content-Type: application/json
```

## **Тело запроса**

Все перечисленные поля обязательны.

| Поле | Тип | Описание и ограничения | Пример |
| --- | --- | --- | --- |
| `username` | `string` | Имя пользователя. Должно быть уникальным. | `Ashen27` |
| `email` | `string` | Адрес электронной почты. Должен содержать символ `@`. | `ashen@example.com` |
| `password` | `string` | Пароль учётной записи. Минимальная длина — 8 символов. | `AshEn34!!` |

### Пример запроса

```json
{
  "username": "Ashen27",
  "email": "ashen@example.com",
  "password": "AshEn34!!"
}
```

## **Успешный ответ**

### `201 Created`

Учётная запись создана.

| Поле | Тип | Описание |
| --- | --- | --- |
| `status` | `integer` | Код статуса, переданный в теле ответа. Значение — `201`. |
| `user` | `object` | Данные созданного пользователя. |
| `user.user_id` | `integer` | Идентификатор пользователя. |
| `user.username` | `string` | Имя пользователя. |
| `user.email` | `string` | Адрес электронной почты пользователя. |

### Пример тела ответа

```json
{
  "status": 201,
  "user": {
    "user_id": 123,
    "username": "Ashen27",
    "email": "ashen@example.com"
  }
}
```

## **Ответы с ошибками**

### Формат тела ошибки

| Поле | Тип | Описание |
| --- | --- | --- |
| `status` | `integer` | Код статуса, переданный в теле ответа. |
| `Title` | `string` | Сообщение об ошибке. Имя поля начинается с заглавной буквы. |

### Условия возникновения ошибок

| HTTP-код | Условие | Сообщение |
| --- | --- | --- |
| `400` | Указанное имя пользователя уже занято. | Имя пользователя уже занято. |
| `405` | Адрес электронной почты не содержит символ `@`. | Неверный формат адреса электронной почты. |
| `406` | Пароль содержит менее 8 символов. | Минимальная длина пароля 8 символов. |

### `400` — имя пользователя уже занято

**Условие:** пользователь с именем `Ashen27` уже существует.

Тело запроса:

```json
{
  "username": "Ashen27",
  "email": "new-user@example.com",
  "password": "AshEn34!!"
}
```

Тело ответа:

```json
{
  "status": 400,
  "Title": "Имя пользователя уже занято."
}
```

### `405` — неверный формат адреса электронной почты

**Условие:** имя `Ashen28` свободно, но значение `email` не содержит символ `@`.

Тело запроса:

```json
{
  "username": "Ashen28",
  "email": "ashen.ru",
  "password": "AshEn34!!"
}
```

Тело ответа:

```json
{
  "status": 405,
  "Title": "Неверный формат адреса электронной почты."
}
```

### `406` — пароль слишком короткий

**Условие:** имя `Ashen29` свободно, адрес электронной почты проходит проверку, но пароль содержит менее 8 символов.

Тело запроса:

```json
{
  "username": "Ashen29",
  "email": "ashen29@example.com",
  "password": "AshEn"
}
```

Тело ответа:

```json
{
  "status": 406,
  "Title": "Минимальная длина пароля 8 символов."
}
```
