# **Описание конечной точки API**

| Метод       | Конечная точка         |Описание |
| ----------- | ---------------------- | ------------------ | 
| `POST`      | /api/v1/users/register |Регистрация нового пользователя в системе. |
	

## **Формат запроса и ответа**
Запрос необходимо передавать в JSON-формате. Любой ответ от ресурса также представлен в JSON-формате.


## **Входные параметры**

| Параметр | Тип данных | Обязательность | Описание | Варианты значений |
| --------- | --------- | --------- | --------- | --------- |
| **username** | string | Обязательно | Имя пользователя | Ashen27 |
| **email** | string | Обязательно | Адрес электронной почты | ashen@yandex.ru |
| **password** | string | Обязательно | Пароль будущей учётной записи | AshEn34!! |

## **Проверки**

| Параметр | Проверка |
| --------- | --------- |
| **username** | Значение должно быть уникальным. Если значение уже имеется в системе, сервис возвращает ответ с кодом 400 и описанием ошибки «Имя пользователя уже занято». |
| **email** | Значение должно содержать символ @. Если значение не имеет символа @, сервис возвращает ответ с кодом 405 и описанием ошибки «Неверный формат адреса электронной почты». |
| **password** | Минимальная длина 8 символов (включительно). Если < 8, сервис возвращает ответ с кодом 406 и описанием ошибки «Минимальная длина пароля 8 символов». |

## **Выходные параметры**

### **1. Положительный ответ**

| Код | Описание |
| --------- | --------- |
| **201** | Регистрация нового пользователя. |

### **201**

`Content-Type: application/json`

Запрос

```json
{
    "username": "Ashen27",
    "email": "ashen@yandex.ru",
    "password": "AshEn34!!"
}	
```

Ответ

```json
{   
    "status": 201,
    "user": {
        "user_id": 123,
        "username":"Ashen27",
        "email":"ashen@yandex.ru"
    }
 }
```

### **2. Ответы с ошибками**

| Код | Описание |
| --------- | --------- |
| **400** | Имя пользователя уже занято. |
| **405** | Неверный формат адреса электронной почты. |
| **406** | Минимальная длина пароля 8 символов. |

### **400**

`Content-Type: application/json`

Запрос

```json
{
    "username": "Ashen27",
    "email": "ashen@yandex.ru",
    "password": "AshEn34!!"
}	
```

Ответ

```json
HTTP/1.1 400
{   
    "status": 400,
    "Title":"Имя пользователя уже занято."
}
```

### **405**

`Content-Type: application/json`

Запрос

```json
{
    "username": "Ashen27",
    "email": "ashen.ru",
    "password": "AshEn34!!"
}	
```

Ответ

```json
HTTP/1.1 405

{   
    "status": 405,
    "Title":"Неверный формат адреса электронной почты."
}
```

### **406**

`Content-Type: application/json`

Запрос

```json
{
    "username": "Ashen27",
    "email": "ashen@yandex.ru",
    "password": "AshEn"
}	
```

Ответ

```json
HTTP/1.1 406

{   
    "status": 406,
    "Title":"Минимальная длина пароля  8 символов."
}
```
