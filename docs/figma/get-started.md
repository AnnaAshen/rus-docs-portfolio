# **Начало работы**
Figma является онлайн-редактором, поэтому для начала работы достаточно создать учетную запись на официальном сайте. Чтобы создать учетную запись Figma, выполните следующие действия:

1. Перейдите на [официальный сайт Figma](https://www.figma.com/).</br>
*Обратите внимание, что интерфейс редактора не доступен на русском языке.*
2. Нажмите **Get started for free**.
3. В открывшемся окне введите **Email** и придумайте пароль (поле **Password**).
4. Нажмите **Create account**. Сервис попросит вас пройти верификацию, чтобы убедиться, что вы не робот.
5. Проверьте электронную почту, которую вы указали при регистрации. На почту придет письмо от Figma со ссылкой для подтверждения учётной записи.
6. В письме нажмите **Verify email**. Вы перейдете на страницу входа в учетную запись Figma.
7. Введите **Email** и пароль (поле **Password**) для входа в учетную запись.
8. Нажмите **Log in**.

Готово — у вас есть учетная запись в Figma.
